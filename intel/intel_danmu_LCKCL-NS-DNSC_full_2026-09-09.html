0核心情报速览

DNS.C 3 : 2 NS.EA （官方 Riot gameWins：NS=2 / DNS=3；Polymarket 整场结算 DNS 100c @20:35）
  • 观众口径“标准假赛 / 剧本让二追三”：NS.EA 先赢两局，随后 G3–G5 被 DNS.C 连扳三局；G3 DNS 盘口出现 0.2c→100c 的 7 分钟 V 型极值。全系列 44 条灰信号弹幕，G3–G5 密集出现“故意送 / 教练指使 / 패작(掉分局)”质疑。观众质疑·非结论 → 详 §2 / §11
  • 关键变量胜负手不在“谁更强”，而在 DNS 上单 Lancer 的送与不送：全系列提及 1409 次（系列第一），观众反复质疑他“故意送 / 教练给他不会的英雄”，但 DNS 赢的三局均由中单 Flip 与 ADC Enosh 后期兜底。本场弹幕 → 关键变量卡
  • 阵容裁决BP 裁决与结果多次背离：G1 弹幕普遍认为 DNS 阵容更好但 NS 赢；G4 弹幕高喊“杰斯必败 / 教练故意给 Lancer 杰斯”，结果 Lancer 确实被打爆，但队伍靠 Flip 阿卡丽赢下。本场弹幕 → 阵容裁决卡 / §3
  • 共识NS 中野 SeTab / MihawK 被反复点名“领先就送”（G3 “세텝 잘 크면 던짐”、G5 “누가 더 많이 던지냐”），与 2:0 后被逆转的过程吻合。本场弹幕 → §7/§8
  • 盘口Polymarket 逐局轨迹与“剧本”叙事一致：G3 DNS 0.2c→100c（18:21→18:28）、整场 20:35 定 DNS 100c。盘口在关键局给出与场面大幅背离的分钟级反转。Polymarket 分钟快照 → §4
一句话决策落点：这场可复用的不是“比分”，而是“Lancer 状态 = DNS 的波动源 + NS 中野领先时的送点”两个可观察变量；G3/G5 的盘口 V 型与弹幕灰词共振，是未来 LCK CL 让分/反向剧本的头号观察项。

LONG / 顺势侧
